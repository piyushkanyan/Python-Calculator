# Travel Planner

A console-based travel planner that recommends a travel mode based on trip distance, weather, and available transportation, then estimates travel time and cost.

## Requirements

- Python 3.x
- No third-party packages are required.

## Run

From the repository root:

```bash
python travel-planner/main.py
```

Enter the requested trip distance and transportation details when prompted. The estimates are illustrative and should not be treated as real-world route or fare data.
