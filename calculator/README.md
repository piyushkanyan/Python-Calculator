# Python Calculator

A console-based calculator supporting basic arithmetic, square roots, maximum/minimum comparisons, and odd/even checks.

## Requirements

- Python 3.x
- No third-party packages; the program uses Python's standard library.

## Run

From the repository root:

```bash
python calculator/Python_calc.py
```

Enter an operation when prompted: `+`, `-`, `*`, `/`, `%`, `**`, `//`, `sr`, `max`, `min`, `odd`, or `even`. The calculator continues until you respond `no` to the repeat prompt.

## Notes

The program is an introductory console application. Some invalid inputs or unsupported mathematical values may raise errors; improving input validation is a suitable next enhancement.
