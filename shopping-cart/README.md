# Shopping Cart

A console-based shopping cart and checkout simulation. It lets a user browse a sample product list, add or remove items, update quantities, and view a cart total.

## Requirements

- Python 3.x
- No third-party packages are required.

## Run

From the repository root:

```bash
python shopping-cart/main.py
```

The program prompts for a budget and provides a menu for product and cart actions. This is a learning project and does not process real payments or securely handle payment credentials.
